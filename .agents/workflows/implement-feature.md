# Implement Feature

1. Read the relevant requirements in `requirements.md`.
2. Read `architecture.md`, `security.md`, `workflow.md`, and `testing.md`.
3. Inspect the existing implementation.
4. Identify affected entities, services, controllers, templates, repositories, and tests.
5. Produce a concise implementation plan.
6. Implement the smallest complete change.
7. Add tests for business and security rules.
8. Run the relevant test suite.
9. Fix failures without weakening tests.
10. Review the diff for accidental scope expansion.
11. Update documentation if behavior changed.
12. Report:
   - What changed
   - Tests run
   - Verification result
   - Remaining issues

Never consider a feature complete merely because it compiles.
