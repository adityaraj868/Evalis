# Project Scope

## Core Scope

The proposal defines the core scope as:

- Authentication
- Role-based authorization
- Exams
- Questions
- Marks
- Re-evaluation requests
- Question-wise aggregation
- Faculty dashboard
- Faculty review
- Revised marks
- Audit logs

## Optional / Advanced

- Automatic question flagging based on a configurable request threshold
- Email/in-app notifications
- Advanced analytics/charts
- Multiple departments/examination types
- Supporting-document uploads where institutional policy permits
- AI-assisted identification of unusual question-level disagreement patterns

Optional features must not destabilize the core workflow.

## Outside Scope

- Conducting online exams
- Automatic answer evaluation
- OCR of handwritten papers
- University-wide deployment
- Government-scale examination infrastructure
